# Profile skeletons

Placeholder-only starting points for the personal profile. `/setup` copies each one to `documents/profile/<same name>` (git-ignored) and fills it in there. The files in this folder never hold personal data and are safe to commit.

| Skeleton | Copied to | Fills the personal parts of |
|---|---|---|
| `candidate.md` | `documents/profile/candidate.md` | `CLAUDE.md` (imported into every session) |
| `01-candidate-profile.md` | `documents/profile/01-candidate-profile.md` | `.claude/skills/job-application-assistant/01-candidate-profile.md` |
| `02-behavioral-profile.md` | `documents/profile/02-behavioral-profile.md` | `.../02-behavioral-profile.md` |
| `03-writing-style.md` | `documents/profile/03-writing-style.md` | writing-style observations from past applications (`03-writing-style.md`) |
| `04-job-evaluation.md` | `documents/profile/04-job-evaluation.md` | the placeholder fields of `.../04-job-evaluation.md` |
| `05-cv-templates.md` | `documents/profile/05-cv-templates.md` | the profile statements in `.../05-cv-templates.md` |
| `06-cover-letter-templates.md` | `documents/profile/06-cover-letter-templates.md` | cover-letter patterns from past applications (`06-cover-letter-templates.md`) |
| `07-interview-prep.md` | `documents/profile/07-interview-prep.md` | STAR examples and tough-question answers in `.../07-interview-prep.md` |
| `.claude/skills/job-scraper/search-queries.md` (no copy here) | `documents/profile/search-queries.md` | the whole search-queries file |
| the active CV template's skeleton | `documents/profile/master-cv.<ext>` | `cv/main_example.tex` as the master CV |

The full rule set is in `CLAUDE.md`, section "Personal Data Storage".
